## 2. 当前验证基线

- 后端：`make test`、`go vet ./...` 已通过。
- 管理端：`npm run test`、`npm run build` 已通过。
- 小程序：`npm test`、`npm run build:weapp`、`npm run build:tt` 已通过。
- 验收脚本覆盖数据库启动门禁、远程开发身份、图片管线和买家页面 smoke；证据目录不纳入源码提交。

## 3. 下一阶段里程碑

### N1 真实平台与生产验收

1. 配置并验证微信/抖音真实登录凭据，完成 F12 买家身份迁移策略。
2. 在 iOS/Android 真机验证登录、游客合并、图片、电话、导航、分享和弱网重试。
3. 完成网关 `/api/v1`、受控 `/uploads` 和证书/合法域名核对。
4. 按图片回填发布顺序执行 dry-run、canary、分批回填和严格模式切换。

### N2 架构收敛

1. 保持模块化单体，优先抽出订单/库存应用服务，避免继续扩大 handler。
2. 为状态机、商户隔离、买家 provider 和上传安全增加架构守护测试。
3. 将 OpenAPI/接口清单与路由检查接入 CI，减少文档漂移。

### N3 运营能力（需求确认后）

1. 评估共享限流和结构化指标，再决定是否引入 Redis/可观测平台。
2. 评估商家子账号/RBAC；没有明确权限矩阵前不扩展 STAFF 接口。
3. 支付、退款、售后、聊天和推荐继续作为独立项目，不混入当前轻量订单模型。

每个新里程碑必须同时提供：实现代码、迁移（如有）、自动化测试、当前文档更新、发布/回滚说明。生产状态只能由实际环境证据确认，不能只勾选历史计划中的 checkbox。
